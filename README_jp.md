# tch-fpc

PyTorch の C++ API (libtorch) に対する Free Pascal バインディング。
[tch-rs](https://github.com/LaurentMazare/tch-rs) に触発されたプロジェクト。

**状態:** 構想段階。まだ使えるものはない。
