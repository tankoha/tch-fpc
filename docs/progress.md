## Goals

- **Theme A (DESIGN 7):** an LLM-facing knowledge package (skill with
  examples, pitfalls and traps) shipped in this repository, so that users
  and their coding agents (Claude Code, Hermes) write correct tch-fpc code.
- **Theme B (DESIGN 8):** a tch-fpc sample that fine-tunes the local
  Qwen3.8 27B (LoRA on the GGUF's packed weights) to write better Pascal in
  five dialects, on the two RX 9070 cards; the code to be generated by the
  local Qwen through the Hermes SDLC process. Stop and discuss if it turns
  out infeasible.
