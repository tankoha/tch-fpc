## 目標

- **テーマ A（DESIGN 7）：** LLM 向けの知識パッケージ（例・落とし穴・罠を含むスキル）を
  このリポジトリで配布し、利用者とそのコーディングエージェント（Claude Code、Hermes）が
  正しい tch-fpc のコードを書けるようにする。
- **テーマ B（DESIGN 8）：** ローカルの Qwen3.8 27B を、5つの方言の Pascal をうまく書ける
  ようにファインチューニングする tch-fpc のサンプル（GGUF の詰めた重みの上で LoRA）。
  RX 9070 の2枚で行い、コードはローカルの Qwen が Hermes の SDLC の工程で生成する。
  実現できないと分かったら止まって相談する。
