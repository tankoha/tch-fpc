# T18 System Flow: qlora_merge

## Components Used

| Component | Purpose |
|---|---|
| `GgufFile` | Read base GGUF metadata and tensor data |
| `GgufQuant` | Dequantize tensors to fp32, quantize to Q8_0 |
| `GgufWriter` | Write merged GGUF file |
| `QwenBlocks` | Read model dimensions, determine block kinds |
| `Lora` | TLoraSet, TLoraPair for LoRA adapters |
| `Checkpoint` | Read run state, load adapters from lora.ot |
| `TrainCli` | Extract sha256 from base filename |

## Who Runs It

### Harness Owner
- On the rehearsal model (M2: a checkpoint of qlora_train; H47 with the bundled llama-server)
- Unit tests on the tiny model

### User
- On the trained 27B model (M4)
- Creates Ollama model with `ollama create`

## Inputs

From T17's training run:
- Checkpoint directory with `state.json` (rank, scale, base_sha256)
- Adapter file `lora.ot` (saved LoRA weights)

Base model:
- GGUF file with sha256 in filename or provided via `--base-sha256`

## Unit Test Environment

- Tiny model from `tests/ut/QwenBlocksFixture.pas`
  - Weights from seed 5, tied head, no MTP (TinyPath)
  - Same with MTP key (NextNPath)
- Two trunk blocks:
  - blk.0 linear: `attn_qkv` (Q8_0 64→128), `attn_gate` (F16 64→64), `ssm_out` (Q8_0 64→64)
  - blk.1 full: `attn_q` (Q8_0 64→256), `attn_k` (Q8_0 64→64), `attn_v` (F16 64→64), `attn_output` (Q8_0 128→64)
- Test fixture provides helper functions
- GPUs hidden during test run

## ITa Environment

Driver: `tests/ita/T18-run.sh`

Runs on CPU from fresh directory outside project:
1. Train on `tests/ita/T17/train.jsonl` (8 records, 4 epochs, lr 1e-3, warm-up 1)
2. Merge checkpoint `ckpt-00000004`
3. Run `merge_check` against H47 reference

Reference: `work/oracle/T18/expected.jsonl`
- Generated by bundled `llama-server` on all-F32 copy of prototype's merged file
- Flags: `-ctk f32 -ctv f32 -fa off`

Result file: `<project root>/work/ita/T18/summary.tsv`
