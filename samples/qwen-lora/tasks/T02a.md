# Task T02a: the T02 documents (no code)

T02 is the unit `GgufQuant` (scalar dequantisers and the Q8_0 quantiser),
split into T02a (documents), T02b1 and T02b2 (the unit and its UT, two
stages) and T02c (the ITa run). This is T02a. It uses **2 delegations**.

Read `{proj}/tasks/T02-facts.md` first: it fixes the arithmetic, the block
layouts, the interface, the UT viewpoints and the ITa cases. The documents
only restate and organise it; do not change any decision in it. Do not read
DESIGN.md, other task files or any source under `src/` or `tests/` (the
facts quote the part of `GgufFile` you need).

Main agent (you):
1. Write `{proj}/docs/external-design/T02-external.md` (the unit's purpose,
   its interface as in the facts, the errors it raises) and
   `{proj}/docs/system-flow/T02-system.md` (who calls it: T03 compares with
   it, T10 dequantises weights through `GgufQuantT`, T18 quantises merged
   tensors; the ITa driver `tests/ita/T02/quant_check.pas` reads every
   tensor with `GgufFile` and passes it through `GgufQuant`).
2. Write `{proj}/tests/ita/cases/T02-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, exactly the seven cases
   ITa-T02-001 to 007 of the facts' ITa table, and under the table the one
   command that runs them all:
   `QLORA_MODEL=<absolute path of the rehearsal GGUF> {proj}/tests/ita/T02-run.sh`
   and where it writes its result (`{proj}/work/ita/T02/summary.tsv`).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`): write `{proj}/docs/detailed-design/T02-detailed.md`
   (one section per routine of the facts' interface, plus the private
   helpers the facts name: `ScaleMin` and one dequantiser per type; each
   with its steps in the facts' order and its errors) and
   `{proj}/docs/program-flow/T02-GgufQuant-flow.md`.
   Then run `~/.hermes/agent-hooks/sdlc.bb review {proj}` and check the two
   files exist and nothing else changed.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/GgufQuant.cases.md` (IDs
   `UT-GgufQuant-NNN`) covering every item of the facts' "Unit tests" list
   and every error of the detailed design. Number the rows of stage 1
   (conversions, `RoundHalfAway`, f32/f16/bf16/q8_0 dequantisation,
   `DequantizeRow`/`DequantizeBytes` errors, the Q8_0 quantiser) from 001,
   and the rows of stage 2 (q4_K, q5_K, q6_K) from 101. Each hand-computed
   block row gives its input bytes and its expected values. No source code.
   Then run the review again.

Write each file in pieces of at most about 150 lines (`patch` or several
`write_file` calls), never a whole long file in one reply.

Report at the end: files written, the number of rows of each case table
(stage 1 and stage 2 separately), the review's output.
