# Task T02c: the T02 ITa run

Read `{proj}/tasks/T02-facts.md`, section "ITa", first. T02b is done:
`{proj}/src/GgufQuant.pas` passes its UT. This task uses **1 delegation**.
`$QLORA_MODEL` is set for this run (the absolute path of the rehearsal
model).

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T02-run.sh`, `{proj}/tests/ita/T02/quant_check.pas` or
`{proj}/work/oracle/T02/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `QLORA_MODEL="$QLORA_MODEL" bash {proj}/tests/ita/T02-run.sh` with
     `terminal`, workdir `{proj}`, **timeout 600** (it takes about two
     minutes; the default of 180 s may cut it).
   - Read `{proj}/work/ita/T02/summary.tsv` with `read_file`. Its columns:
     case ID, OK/NG, diff lines, lines ours, lines oracle, note; the last
     line reports the driver's exit code and stderr.
   - Add one row per case ITa-T02-001 to 007 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` and putting the
     three numbers in the notes (`diff 0, 133/133 lines`). Write nothing
     that is not in `summary.tsv` or in a file it names.
   - For an NG case, read its `ITa-T02-NNN.diff` (first lines) and record
     in `{proj}/docs/defects.md` the tensors that differ (from the diff)
     with the cause "切り分け待ち" (to be isolated).
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the sub-agent's
   rows in `ita.md` with `summary.tsv` line by line.
3. Judge any NG yourself and record it in `{proj}/docs/defects.md`.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
