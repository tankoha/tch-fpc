# Task T03a: the T03 documents (no code)

T03 is the unit `GgufQuantT` (T02's dequantisers and Q8_0 quantiser in
tensor ops), split into T03a (documents), T03b (the unit and its UT, two
delegations) and T03c (the ITa run). This is T03a. It uses
**2 delegations**.

Read `{proj}/tasks/T03-facts.md` first: it fixes the formulas, the
interface, the UT viewpoints, the ITa and the case-ID ranges. The documents
only restate and organise it. Do not read DESIGN.md, other task files or
any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T03-external.md` (purpose, the
   interface and its errors, as in the facts) and
   `{proj}/docs/system-flow/T03-system.md` (callers: T10 dequantises
   weights on a device, T18 quantises merged tensors; the UT compares with
   T02's `GgufQuant`; the ITa driver `tests/ita/T03/quantt_check.pas`).
2. Write `{proj}/tests/ita/cases/T03-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T03-001 to 007 as in
   the facts (the same comparisons as ITa-T02-001 to 007, with GgufQuantT),
   and under the table the command
   `QLORA_MODEL=<absolute path of the rehearsal GGUF> {proj}/tests/ita/T03-run.sh`
   and its result file `{proj}/work/ita/T03/summary.tsv`.
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`): write
   `{proj}/docs/detailed-design/T03-detailed.md` (one section per type's
   dequantisation, one for the quantiser, one for each check and error;
   each with the tensor-op sequence of the facts) and
   `{proj}/docs/program-flow/T03-GgufQuantT-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
   that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/GgufQuantT.cases.md` (IDs
   `UT-GgufQuantT-NNN`; stage 1 from 001, stage 2 from 101, as the facts
   say) covering every item of the facts' "Unit tests" list. Expected
   values of the hand cases are hex bits copied from
   `{proj}/tests/ut/cases/GgufQuant.cases.md` (T02); the random cases say
   their seed and that the oracle is `GgufQuant`. No source code. Then run
   the review again and check the file with `ls -l`.

Report at the end: the `ls -l` of every file written, the number of rows
of the case table (stage 1 and 2), the review's output.
