# Task T04a: the T04 documents (no code)

T04 is the unit `GgufWriter` (the GGUF writer that T18 uses), split into
T04a (documents), T04b1 and T04b2 (the unit and its UT, one stage each)
and T04c (the ITa run). This is T04a. It uses **2 delegations**.

Read `{proj}/tasks/T04-facts.md` first: it fixes the file layout, the
interface, the UT rows, the ITa and the case-ID ranges. The documents only
restate and organise it. Do not read DESIGN.md, other task files or any
source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T04-external.md` (purpose, the
   interface and its errors, as in the facts) and
   `{proj}/docs/system-flow/T04-system.md` (callers: T18 `qlora_merge`
   writes the merged model; the UT reads the output back with T01
   `GgufFile`; the ITa driver `tests/ita/T04/writer_check.pas` compares with
   upstream ggml's own GGUF code).
2. Write `{proj}/tests/ita/cases/T04-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T04-001 to 006 as in
   the facts, and under the table the command
   `QLORA_MODEL=<absolute path of the rehearsal GGUF> <project root>/tests/ita/T04-run.sh`
   and its result file `<project root>/work/ita/T04/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`): write `{proj}/docs/detailed-design/T04-detailed.md`
   (one section per routine of the interface, one for `Layout`, one for
   each error; each with the steps and numbers of the facts) and
   `{proj}/docs/program-flow/T04-GgufWriter-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
   that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/GgufWriter.cases.md` with exactly the
   rows of the facts' "Unit tests" table (IDs `UT-GgufWriter-001` to `010`
   and `101` to `115`, 25 rows; columns as in
   `{proj}/tests/ut/cases/GgufQuantT.cases.md`), the expected values copied
   from the facts. No source code. Then run the review again and check the
   file with `ls -l` and count its rows with
   `grep -c '^| UT-GgufWriter-' {proj}/tests/ut/cases/GgufWriter.cases.md`.

Report at the end: the `ls -l` of every file written, the row count of the
case table, the review's output.
