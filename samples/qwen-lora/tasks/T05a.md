# Task T05a: the T05 documents (no code)

T05 is the tokenizer (`QwenTokenizer`), its command line (`TokenizeCli`,
`qlora_tokenize`) and H46, split into T05a (documents), T05b1, T05b2,
T05b3 (the units and their UT, one stage each) and T05c (the ITa run).
This is T05a. It uses **2 delegations**.

Read `{proj}/tasks/T05-facts.md` first: it fixes the algorithm, the
interfaces, the UT rows, the ITa and the case-ID ranges. The documents only
restate and organise it. Do not read DESIGN.md, other task files or any
source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T05-external.md` (purpose, H46, the
   two units' interfaces and errors, the command line and its exit codes,
   as in the facts) and `{proj}/docs/system-flow/T05-system.md` (callers:
   T07 renders chats and T15 tokenises training records with
   `QwenTokenizer`; `qlora_tokenize` is used by the data pipeline; the UT
   use the fixture `tests/ut/TokenizerFixture.pas`; the ITa compares with
   llama-server's `/tokenize`).
2. Write `{proj}/tests/ita/cases/T05-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T05-001 to 008 as in
   the facts, and under the table the command
   `QLORA_MODEL=<absolute path of the rehearsal GGUF> <project root>/tests/ita/T05-run.sh`
   and its result file `<project root>/work/ita/T05/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`): write `{proj}/docs/detailed-design/T05-detailed.md`
   (one section per routine: ByteToUnicode, Init, Create, CreateFromVocab,
   PreTokenize, EncodeWord, Encode, Decode, SpecialId, RunTokenizeCLI;
   each with the steps of the facts, the scanner and the BPE loop as the
   facts' pseudo-code) and `{proj}/docs/program-flow/T05-QwenTokenizer-flow.md`.
   Then run `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with
   `ls -l` that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the two
   UT case tables with exactly the rows of the facts' "Unit tests" tables:
   `{proj}/tests/ut/cases/QwenTokenizer.cases.md` (`UT-QwenTokenizer-001`
   to `029` and `101` to `127`, 56 rows) and
   `{proj}/tests/ut/cases/TokenizeCli.cases.md` (`UT-TokenizeCli-001` to
   `019`, 19 rows); columns as in `{proj}/tests/ut/cases/GgufWriter.cases.md`;
   the expected values copied from the facts. No source code. Then run the
   review again and count the rows with
   `grep -c '^| UT-' {proj}/tests/ut/cases/QwenTokenizer.cases.md {proj}/tests/ut/cases/TokenizeCli.cases.md`.

Report at the end: the `ls -l` of every file written, the row counts, the
review's output.
