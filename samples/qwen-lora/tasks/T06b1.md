Environment variables (decided, do not investigate): `ReadEnvRec` does not
read the environment. Its signature is
`function ReadEnvRec(const AFpc, AFpcUnleashed, AHome: string): TEnvRec`:

variables. Reason: in FPC 3.2.2, `GetEnvironmentVariable` reads a copy
taken at program start, so a value set later with libc `setenv` is not
seen. Update section 2.1 of the detailed design and the `ReadEnvRec` rows
of the case table to this signature (retire rows that set the environment,
add rows for the new form).
