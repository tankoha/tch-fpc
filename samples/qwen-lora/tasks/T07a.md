# Task T07a: the T07 documents (no code)

**Write carefully:** this unit renders chat templates whose tags are
special tokens of Qwen and look like the tags your own model uses for
thinking and for tool calls. Never write a tag literally (in messages,
goals, summaries, documents, tables or code): use the placeholders and
constants of section "Tags" of `{proj}/tasks/T07-facts.md`, and tell the
sub-agent the same.

T07 is the unit `QwenChat` (the chat template of the deployed Qwen for
text turns, and a training sample with the span the loss covers), split
into T07a (documents), T07b1, T07b2 and T07b3 (the unit and its UT, one
stage each) and T07c (the ITa run). This is T07a. It uses **2
delegations**.

Read `{proj}/tasks/T07-facts.md` first: it fixes the template, the
interface, the implementation, the messages, the UT rows, the ITa and the
case-ID ranges. The documents only restate and organise it. Do not read
DESIGN.md, other task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T07-external.md` (purpose, the
   rendering rules 1 to 4 of the facts with the placeholders, trimming,
   the interface and its errors) and `{proj}/docs/system-flow/T07-system.md`
   (callers: T15 builds the training samples with `EncodeTraining`; T20
   renders evaluation prompts with `RenderChat`; the UT compares with hand
   texts and T05's UT vocabulary; the ITa driver
   `tests/ita/T07/chat_check.pas` compares with the bundled llama-server's
   `/apply-template` and `/tokenize` under the 27B model's template).
2. Write `{proj}/tests/ita/cases/T07-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T07-001 to 004 as in
   the facts (the expected column gives the limit), and under the table
   the command `QLORA_MODEL=<rehearsal GGUF> <project root>/tests/ita/T07-run.sh`
   and its result file `<project root>/work/ita/T07/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`): write `{proj}/docs/detailed-design/T07-detailed.md`
   (one section for the helpers, one for `Render` with its steps, one for
   `RenderTraining` and `EncodeTraining`, one for the checks with every

   `{proj}/docs/program-flow/T07-QwenChat-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`

4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/QwenChat.cases.md` with exactly the
   rows of the facts' "Unit tests" tables (IDs `UT-QwenChat-001` to `027`
   and `101` to `107`, 34 rows; columns as in
   `{proj}/tests/ut/cases/GgufWriter.cases.md`), the inputs and expected
   values copied from the facts with their placeholders. No source code.
   Then run the review again and check the file with `ls -l` and count its

Report at the end: the `ls -l` of every file written, the row count of the
case table, the review's output.
