# Task T07c: the T07 ITa run

**Write carefully:** this unit renders chat templates whose tags are
special tokens of Qwen and look like the tags your own model uses for
thinking and for tool calls. Never write a tag literally in your messages,
goals or summaries; refer to them in words. The ITa's output has none.

Read `{proj}/tasks/T07-facts.md`, section "ITa", first. T07b is done
(stages 1 to 3): `{proj}/src/QwenChat.pas` passes its UT. This task uses
**1 delegation**. `$QLORA_MODEL` is set for this run (the absolute path of
the rehearsal model).

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T07-run.sh`, `{proj}/tests/ita/T07/chat_check.pas` or
`{proj}/work/oracle/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `QLORA_MODEL="$QLORA_MODEL" bash {proj}/tests/ita/T07-run.sh` with
     `terminal`, workdir `{proj}`, **timeout 600**.
   - Read `{proj}/work/ita/T07/summary.tsv` with `read_file` (columns: case
     ID, OK/NG, value, limit, note; then the driver's exit code and the
     stderr line count).
   - Add one row per case ITa-T07-001 to 004 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` with the value and
     the limit in the notes (`value 0, limit 0, 14 conversations`).
   - For an NG case, read `{proj}/work/ita/T07/details.txt` (one line per
     record) and record the case in `{proj}/docs/defects.md` with the NG
     record IDs and the cause "切り分け待ち".
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in
   `ita.md` with `summary.tsv` line by line.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
