# Task T08a: the T08 documents (no code)

T08 is the unit `DeltaRule` (the gated delta rule, token by token: the
reference form that T09's chunked form is checked against), split into
T08a (documents), T08b1 and T08b2 (the unit and its UT, one stage each)
and T08c (the ITa run). This is T08a. It uses **2 delegations**.

Read `{proj}/tasks/T08-facts.md` first: it fixes the rule, the interface,
the implementation, the messages, the UT rows, the ITa and the case-ID
ranges. The documents only restate and organise it. Do not read DESIGN.md,
other task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T08-external.md` (purpose, the rule,
   the interface and its errors, as in the facts) and
   `{proj}/docs/system-flow/T08-system.md` (callers: T10's linear block
   calls it per sequence; T09's chunked form is checked against it; the UT
   compares with the fixture's scalar reference `RefTokens` and hand
   values; the ITa driver `tests/ita/T08/deltarule_check.pas` runs it at
   the 27B model's sizes).
2. Write `{proj}/tests/ita/cases/T08-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T08-001 to 007 as in
   the facts (the expected column gives the limit), and under the table
   the command `<project root>/tests/ita/T08-run.sh` (no variable is
   needed) and its result file `<project root>/work/ita/T08/summary.tsv`
   (write `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`): write
   `{proj}/docs/detailed-design/T08-detailed.md` (one section for
   `DeltaStep`, one for `DeltaRuleTokens`, one for the checks with every
   message in order; each with the tensor-op sequence of the facts) and
   `{proj}/docs/program-flow/T08-DeltaRule-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
   that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/DeltaRule.cases.md` with exactly the
   rows of the facts' "Unit tests" tables (IDs `UT-DeltaRule-001` to `016`
   and `101` to `117`, 33 rows; columns as in
   `{proj}/tests/ut/cases/GgufWriter.cases.md`), the inputs and expected
   values copied from the facts. No source code. Then run the review again
   and check the file with `ls -l` and count its rows with
   `grep -c '^| UT-DeltaRule-' {proj}/tests/ut/cases/DeltaRule.cases.md`.

Report at the end: the `ls -l` of every file written, the row count of the
case table, the review's output.
