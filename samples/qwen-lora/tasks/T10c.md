(stages 1 to 4): `PackedLinear` and `QwenBlocks` pass their UT. This task uses
**1 delegation**. `$QLORA_MODEL` is set for this run (the absolute path of

`{proj}/tests/ita/T10-run.sh`, `{proj}/tests/ita/T10/blocks_check.pas`,
`{proj}/tests/ut/QwenRefScalar.pas` or `{proj}/tests/ut/QwenBlocksFixture.pas`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):

     ID, OK/NG, value, limit, note; then the driver's exit code and the

     with `patch`, copying the result from `summary.tsv` with the value and

2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
