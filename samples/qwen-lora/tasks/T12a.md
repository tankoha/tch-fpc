# Task T12a: the T12 documents (no code)

T12 is the unit `Lora` (LoRA adapters: `TLoraPair`, `TLoraSet`) and the
places that use it: `TPackedLinear.Lora`, `TQwenBlock.Target` /
`LoraTargets` / `Index` and `TQwenModel.AttachLora`. It is split into T12a
(documents), T12b1 to T12b4 (the code and its UT, one stage each) and T12c
(the ITa run). This is T12a. It uses **2 delegations**. **No source code
and no tests are written in T12a**: not by you, not by the sub-agent.

Read `{proj}/tasks/T12-facts.md` first: it fixes the interfaces, the
implementation, the messages, the UT rows, the ITa and the case-ID ranges.
The documents only restate and organise it. Do not read DESIGN.md, other
task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T12-external.md` (purpose of the unit
   and of the additions, the forward of an adapted matrix
   `y = x·Wᵀ + s·((x·Aᵀ)·Bᵀ)`, the initialisation and why B starts at zero,
   the names, the targets per block kind, one store per device, the file of
   `Save`/`Load`, the errors, as in the facts) and
   `{proj}/docs/system-flow/T12-system.md` (callers: T16's checkpoint
   saves and loads the set, T17's training attaches the set to the model
   and gives its stores' variables to T14's `LoraOptim`, T18's merge reads
   `MergedDelta`; the UT on the tiny models of
   `tests/ut/QwenBlocksFixture.pas`; the ITa driver
   `tests/ita/T12/lora_check.pas` on the rehearsal model).
2. Write `{proj}/tests/ita/cases/T12-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T12-001 to 005 as in
   the facts (the expected column gives the limit), and under the table
   the command `QLORA_MODEL=<rehearsal GGUF> <project root>/tests/ita/T12-run.sh`
   and its result file `<project root>/work/ita/T12/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`). Put this sentence into the goal
   itself: "Write only the two documents named here; no source code, no
   tests, no case tables; stop when both files exist." The documents:
   `{proj}/docs/detailed-design/T12-detailed.md` (sections: `LoraPath`;
   `TLoraPair` (`Create`, `Delta`, `MergedDelta`); `TLoraSet` (`Create`,
   `Destroy`, `StoreFor`, `Add`, `Count`, `Pair`, `Find`, `Stores`,
   `ParameterCount`, `Save`, `Load`); `TPackedLinear.SetLora` and
   `Forward`; `TQwenBlock.Target`, `LoraTargets`, `Index`;
   `TQwenModel.AttachLora`; the checks with every message in order; each
   with the tensor-op sequence of the facts) and
   `{proj}/docs/program-flow/T12-Lora-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
