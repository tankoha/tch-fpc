# Task T12c: the T12 ITa run

Read `{proj}/tasks/T12-facts.md`, section "ITa", first. T12b is done
(stages 1 to 4): `Lora` and the additions pass their UT. This task uses
**1 delegation**. `$QLORA_MODEL` is set for this run (the absolute path of
the rehearsal model).

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T12-run.sh`, `{proj}/tests/ita/T12/lora_check.pas` or
anything under `{proj}/work/oracle/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `QLORA_MODEL="$QLORA_MODEL" bash {proj}/tests/ita/T12-run.sh` with
     `terminal`, workdir `{proj}`, **timeout 600**.
   - Read `{proj}/work/ita/T12/summary.tsv` with `read_file` (columns: case
     ID, OK/NG, value, limit, note; then the exit code and the stderr line
     count).
   - Add one row per case ITa-T12-001 to 005 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` with the value and
     the limit in the notes (`value 4.8E-005, limit 1.0E-003`).
   - For an NG case, record it in `{proj}/docs/defects.md` with the value,
     the limit and the cause "切り分け待ち".
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in
   `ita.md` with `summary.tsv` line by line.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
