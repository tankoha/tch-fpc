# Task T13a: the T13 documents (no code)

T13 is the unit `Recompute` (the block-wise backward by recomputation:
the forward without a graph keeps every stage's input, the backward runs
each stage again with a graph, last to first), split into T13a
(documents), T13b1 and T13b2 (the unit and its UT, one stage each) and
T13c (the ITa run). This is T13a. It uses **2 delegations**.

Read `{proj}/tasks/T13-facts.md` first: it fixes the interface, the
implementation, the messages, the UT rows, the ITa and the case-ID
ranges. The documents only restate and organise it. Do not read DESIGN.md,
other task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T13-external.md` (purpose, the two
   passes, the interface and its errors, as in the facts) and
   `{proj}/docs/system-flow/T13-system.md` (callers: T17's training step
   runs the 64 trunk blocks as stages on the two GPUs, saved inputs on the
   host; the UT compares with hand values of the fixture's scale stages
   and with the fixture's `WholeGraphBackward`; the ITa driver
   `tests/ita/T13/recompute_check.pas` runs 8 and 64 stages on the CPU).
2. Write `{proj}/tests/ita/cases/T13-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T13-001 to 005 as in
   the facts (the expected column gives the limit), and under the table
   the command `<project root>/tests/ita/T13-run.sh` (no variable is
   needed) and its result file `<project root>/work/ita/T13/summary.tsv`
   (write `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`): write
   `{proj}/docs/detailed-design/T13-detailed.md` (one section for
   `TSavedInputs`, one for `RecomputeForward`, one for
   `RecomputeBackward`, one for the checks with every message in order;
   each with the steps of the facts' "Implementation") and
   `{proj}/docs/program-flow/T13-Recompute-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
   that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`): write the UT
   case table `{proj}/tests/ut/cases/Recompute.cases.md` with exactly the
   rows of the facts' "Unit tests" tables (IDs `UT-Recompute-001` to `013`
   and `101` to `108`, 21 rows; columns as in
   `{proj}/tests/ut/cases/GgufWriter.cases.md`), the inputs and expected
   values copied from the facts. No source code. Then run the review again
   and check the file with `ls -l` and count its rows with
   `grep -c '^| UT-Recompute-' {proj}/tests/ut/cases/Recompute.cases.md`.

Report at the end: the `ls -l` of every file written, the row count of the
case table, the review's output.
