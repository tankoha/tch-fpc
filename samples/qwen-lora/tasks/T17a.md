# Task T17a: the T17 documents (no code)

T17 is the training program `qlora_train`: the unit `TrainStep` (one
sample's loss and gradient, the validation loss), the unit `TrainCli`
(the command line, the loop, the log, checkpoints, resume) and the
program `src/qlora_train.pas` (the harness owner's, complete). It is split
into T17a (documents), T17b1 to T17b3 (the code and its UT, one stage
each) and T17c (the ITa run). This is T17a. It uses **2 delegations**.
**No source code and no tests are written in T17a**: not by you, not by
the sub-agent.

Read `{proj}/tasks/T17-facts.md` first: it fixes the interfaces, the
implementation, the messages, the UT rows, the ITa and the case-ID ranges.
The documents only restate and organise it. Do not read DESIGN.md, other
task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T17-external.md` (purpose of the
   program, the command line with every option and its default, one
   sample per forward, one update, the schedule's total, checkpoints and
   resume with the configuration hash and the base's sha256, the log, the
   exit codes, the errors, as in the facts) and
   `{proj}/docs/system-flow/T17-system.md` (what it uses: QwenModel,
   Lora, Recompute, LoraOptim, TrainData, Checkpoint; who runs it: the
   harness owner on the rehearsal model (M2), the user on the GPUs (M2g,
   M4); its outputs for T18's merge; the UT on the tiny model; the ITa
   with its four runs and the driver).
2. Write `{proj}/tests/ita/cases/T17-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T17-001 to 006 as in
   the facts (the expected column gives the limit), and under the table
   the command `QLORA_MODEL=<rehearsal GGUF> <project root>/tests/ita/T17-run.sh`
   and its result file `<project root>/work/ita/T17/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`). Put this sentence into the goal
   itself: "Write only the two documents named here; no source code, no
   tests, no case tables; stop when both files exist." The documents:
   `{proj}/docs/detailed-design/T17-detailed.md` (sections: `TrainStep`
   (`Targets`, `SliceLoss`, `CheckSample`, `SampleLossBackward`,
   `SampleLoss`, `ValidationLoss`); `TrainCli` (`TTrainConfig`,
   `DefaultTrainConfig`, `ParseTrainArgs` with `Int` and `Num`,
   `ShaFromName`, `ConfigHash`, `TotalUpdates`, `AppendLine`, `G17`,
   `RunTrainCLI` step by step); the checks with every message in order)
   and `{proj}/docs/program-flow/T17-qlora_train-flow.md`. Then run
   `~/.hermes/agent-hooks/sdlc.bb review {proj}`, and check with `ls -l`
   that both files exist before you report them.
4. Delegate (2 of 2) to the sub-agent (skill `sdlc-ut-tdd`). Put this
   sentence into the goal itself: "Write only the case tables named here;
   no source code, no tests; do not run the gate; stop when the tables are
   written." The tables, with exactly the rows of the facts' "Unit tests"
   tables (columns as in `{proj}/tests/ut/cases/GgufWriter.cases.md`), the
   inputs and expected values copied from the facts:
   `{proj}/tests/ut/cases/TrainStep.cases.md` (new): rows
   `UT-TrainStep-001` to `009`; `{proj}/tests/ut/cases/TrainCli.cases.md`
   (new): rows `UT-TrainCli-101` to `108` and `201` to `212`. Then run the
   review again and count the rows with `grep -c '^| UT-' <file>`.

Report at the end: the `ls -l` of every file written, the row counts, the
review's output.
