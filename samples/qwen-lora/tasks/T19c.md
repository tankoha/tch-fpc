# Task T19c: the T19 ITa run

Read `{proj}/tasks/T19-facts.md`, section "ITa", first. T19b is done
(stages 1 and 2): `DatasetFilter` and `DatasetCli` pass their UT. This task uses
**1 delegation**. `$QLORA_MODEL` is set for this run (the absolute path of
the rehearsal model).

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T19-run.sh`, anything under `{proj}/tests/ita/T19/` (the
driver `check.bb`, `raw.jsonl`, `eval.jsonl`, `examples/`, `ref-tokens.jsonl`, `expected.tsv`, `make-raw.bb`, `make-ref.bb`), `{proj}/src/qlora_dataset.pas`
or anything under `{proj}/work/oracle/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `QLORA_MODEL="$QLORA_MODEL" bash {proj}/tests/ita/T19-run.sh` with
     `terminal`, workdir `{proj}`, **timeout 900**.
   - Read `{proj}/work/ita/T19/summary.tsv` with `read_file` (columns: case
     ID, OK/NG, value, limit, note; then the exit codes of the runs and
     the stderr line count).
   - Add one row per case ITa-T19-001 to 006 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` with the value and
     the limit in the notes (`value 0.0E+000, limit 0.0E+000`).
   - For an NG case, record it in `{proj}/docs/defects.md` with the value,
     the limit and the cause "切り分け待ち".
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in
   `ita.md` with `summary.tsv` line by line.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
