# Task T20c: the T20 ITa run

Read `{proj}/tasks/T20-facts.md`, section "ITa", first. T20b is done
(stages 1 and 2): `EvalReport` and `EvalCli` pass their UT. This task uses
**1 delegation**. No model file is needed.

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T20-run.sh`, anything under `{proj}/tests/ita/T20/` (the
driver `check.bb`, `tasks.jsonl`, `replies-before.jsonl`,
`replies-after.jsonl`, `refs/`, `make-tasks.bb`, `ask.bb`),
`{proj}/src/qlora_eval.pas`, `{proj}/src/qlora_verify.pas` or anything
under `{proj}/work/oracle/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `bash {proj}/tests/ita/T20-run.sh` with `terminal`, workdir
     `{proj}`, **timeout 900**.
   - Read `{proj}/work/ita/T20/summary.tsv` with `read_file` (columns: case
     ID, OK/NG, value, limit, note; then the exit codes of the runs and
     the stderr line count).
   - Add one row per case ITa-T20-001 to 005 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` with the value and
     the limit in the notes (`value 0, limit 0`).
   - For an NG case, record it in `{proj}/docs/defects.md` with the value,
     the limit and the cause "切り分け待ち".
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in
   `ita.md` with `summary.tsv` line by line.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
