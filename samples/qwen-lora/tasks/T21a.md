# Task T21a: the T21 documents (no code)

T21 adds bf16 compute (the matrix products of the trunk blocks) and draws
the adapters' initial values on the CPU: `TPackedLinear.Compute`,
`TLoraPair.Create`, `TQwenModel.Compute`, and the option `--compute
fp32|bf16` of `qlora_train` (`TrainCli`) and `qlora_logprobs`
(`LogprobsCli`). It is split into T21a (documents), T21b1 and T21b2 (the
code and its UT, one stage each) and T21c (the ITa run). This is T21a. It
uses **2 delegations**. **No source code and no tests are written in
T21a**: not by you, not by the sub-agent.

Read `{proj}/tasks/T21-facts.md` first: it fixes the interfaces, the
implementation, the messages, the UT rows, the ITa and the case-ID ranges.
The documents only restate and organise it. Do not read DESIGN.md, other
task files or any source under `src/` or `tests/`.

Main agent (you):
1. Write `{proj}/docs/external-design/T21-external.md` (purpose: bf16 on
   the GPUs, fp32 on the CPU by default; which products run in bf16 and
   what stays fp32, and why the head stays fp32; the initial values drawn
   on the CPU and why; the option `--compute` of both programs, its
   default, that it is not in the configuration hash; the errors, as in
   the facts) and `{proj}/docs/system-flow/T21-system.md` (who uses it:
   M2g-b, the two-card split in bf16 against the CPU curve, run by the
   harness owner; M4, the 27B run and its H43 check in bf16; the UT on the
   tiny model and the stock fpc; the ITa on the CPU against the oracle of
   the code before T21).
2. Write `{proj}/tests/ita/cases/T21-ita.cases.md`: columns
   `| Case ID | Title | Expected (short) |`, cases ITa-T21-001 to 006 as in
   the facts (the expected column gives the limit), and under the table
   the command `QLORA_MODEL=<rehearsal GGUF> <project root>/tests/ita/T21-run.sh`
   and its result file `<project root>/work/ita/T21/summary.tsv` (write
   `<project root>` literally, not the absolute path).
3. Delegate (1 of 2) to the sub-agent (skills `sdlc-detailed-design`,
   `pascal-fpc-objfpc`, `tch-fpc`). Put this sentence into the goal
   itself: "Write only the two documents named here; no source code, no
   tests, no case tables; stop when both files exist." The documents:

   `TPackedLinear` (`Compute`, `SetCompute`, `Forward` with both
