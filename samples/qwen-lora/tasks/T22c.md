# Task T22c: the T22 ITa run

Read `{proj}/tasks/T22-facts.md`, section "ITa", first. T22b is done:
`DialectVerify` passes its UT. This task uses **1 delegation**. The
rehearsal model is given in `QLORA_MODEL` (the T19 ITa needs it).

The ITa is a script prepared by the harness owner. Nobody changes
`{proj}/tests/ita/T22-run.sh`, anything under `{proj}/tests/ita/T22/`
(the driver `check.bb`, `make-files.bb`, `files/`, `expected.tsv`),
anything under `{proj}/tests/ita/T19/`, `{proj}/tests/ita/T19-run.sh`,
`{proj}/src/qlora_verify.pas` or anything under `{proj}/work/oracle/`.

Main agent (you):
1. Delegate to the sub-agent (skill `sdlc-it-execution`):
   - Run `bash {proj}/tests/ita/T22-run.sh` with `terminal`, workdir
     `{proj}`, **timeout 600** (about 20 seconds).
   - Read `{proj}/work/ita/T22/summary.tsv` with `read_file` (columns: case
     ID, OK/NG, value, limit, note; then the exit codes of the runs and
     the stderr line count; `verify 1` is expected: planted faults).
   - Add one row per case ITa-T22-001 to 006 to `{proj}/test-results/ita.md`
     with `patch`, copying the result from `summary.tsv` with the value and
     the limit in the notes (`value 0, limit 0`).
   - For an NG case, record it in `{proj}/docs/defects.md` with the value,
     the limit and the cause "切り分け待ち".
   - Run `~/.hermes/agent-hooks/sdlc.bb gate ita {proj}`.
2. Run `~/.hermes/agent-hooks/sdlc.bb review {proj}`; compare the rows in
   `ita.md` with `summary.tsv` line by line.

Report at the end: the content of `summary.tsv`, the ITa gate's numbers,
open defects.
