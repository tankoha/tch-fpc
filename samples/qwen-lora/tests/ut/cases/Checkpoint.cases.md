# UT cases — unit `Checkpoint` (T16)

Context (T16-facts): `FixState`: Update 5, Epoch 1, Position 37, Seed 16, Rank 0, Scale 0, ConfigHash `cfg-1`, BaseSha256 `abc`, ValLoss 1/3. `NewRun(ASeed, S, O)`: `ManualSeed(ASeed)`; S := a set of rank 4, scale 2 with the pairs `blk.0.attn_qkv` 8 -> 6 and `blk.1.attn_q` 8 -> 10 on the CPU; O := `TLoraAdamW.Create(S.Stores, DefaultAdamWConfig)`. Free O, then S. `Train(S, O, AFrom, ACount)`: updates AFrom .. AFrom + ACount − 1 of a toy problem (loss = Σ over the pairs of ((Delta(X) − Y)²).sum, X [5, 8] = sin(1 + i), Y = cos(1 + i); Backward, `ClipGlobalNorm(1)`, `Step(ScheduleLR(0.01, U, 2, 10, 0.1))`, `ZeroGrad`). `Snapshot(S, O)`: every A and B, then every moment, as Double; `DiffArr(A, B)` (max |a − b|, Infinity for other lengths); `Arr(T)`; `SliceMoments(O, From, To)` (moment variables From..To of store 0, in the store's order m.0, v.0, m.1, ...). `NewRoot` (a fresh directory under the test's temporary directory, not created, ending in the delimiter); `Names(A)` (the file names joined by commas); `TouchFile(F)`; `SameBits(A, B)`. `FixJson(Key, Value)`: the JSON of FixState with Rank 4, Scale 2 and val_loss 0.5, key Key renamed to x<Key> when Value is '', else given Value (the old value stays under y<Key>); `CheckJsonError(Self, Text, Message)`. `CheckLoad(Self, Rank, Scale, Twice, Message)`: saves FixState of `NewRun(16)` and loads it into a set of that rank and scale with the same pairs and AdamW over its store (the store twice when Twice); expects ECheckpoint with Message, `<dir>` replaced by the checkpoint directory. S, O := `NewRun(16)` unless said otherwise; C := `TCheckpoints.Create(NewRoot, 3)` unless said otherwise; free C, then O, then S. Each test frees what it creates in `try ... finally`.

Stage 1 (task T16b1): `NewRunState`, `RunStateToJson`, `RunStateFromJson`, `ReadRunState`; rows UT-Checkpoint-001 to 012. Stage 2 (task T16b2): `TCheckpoints` (all of it); rows UT-Checkpoint-101 to 120.

Error rows catch the named exception class and compare the whole message (`AssertEquals`); a row fails if no exception comes. "exact" means equal strings, equal bits or a difference of 0.
