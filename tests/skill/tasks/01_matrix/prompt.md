Write a Free Pascal program using tch-fpc (unit `Tch`) that builds the 2x3
matrix A with rows (1, 2, 3) and (4, 5, 6) as a float tensor, computes
B = A multiplied by the transpose of A (a matrix product), and prints
exactly these three lines:

    shape 2x2
    B[0,0] = 14.000
    B[1,1] = 77.000

The numbers must come from the tensors, printed with three decimals.
